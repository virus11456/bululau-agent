# 布神四大型態（原文摘自 GTM-Training PDF）

## 布鹿流
布鹿流型態特點
 屬性：順勢
 週期：各週期
 時框：1H、4H、8H較佳
 勝率：週期大則勝率大
 報酬：中性報酬
 頻率：視行情而定
布鹿流型態判斷重點
1. 長紅Ｋ棒組合產生突破
2. 均線上發散開始啟動
3. 量能增溫Ｋ棒
4. 小週期出現延續遞延
5. 大週期不再破低
布鹿流型態作法重點
1. 不做第一波
2. 第一波或第二波回測進場為
   最佳位置
3. 根據Ｋ棒組合或波動幅度設
   計合適風報比（至少1.5）
4. 上漲往小週期找（1H）
5. 下跌往大週期找（4H或8H）
6. 持倉週期視行情延續而定
總結
1. 純論型態為『底底高』現象
2. 趨勢段成立伴隨均線上發散
3. 預測首波進場發動點無意義
4. 延續過多波時可考慮放棄
5. 使用較大週期較易獲利
6. 趨勢跟隨簡易策略
7. 『不追價、買下跌』

## 大師兄
大師兄型態特點
 屬性：中立偏逆勢
 週期：大週期為主
 時框：4H、8H較佳
 勝率：偏低（低於50%）
 報酬：高報酬（大週期下）
 頻率：平均1個月出現1次
大師兄型態判斷重點
1. 長黑Ｋ棒產生破壞（均線下
   發散為明顯判斷）
2. 帶大量Ｋ棒特徵之一
3. 觸底後反彈具強度
4. 著重於二次測前低進場
5. 以不破底為猜想進場
大師兄型態作法重點
1. 現象發生才做規劃
2. 通常為整體集體下跌走勢
3. 長黑當下非進場最佳位
4. 以不破底為猜想進場，風報
   比須合理適當
5. 需考量大週期的停損波動率
6. 時間週期長（等待進場與持
   倉時間較長）
反轉型態（4H）
反轉型態（8H）
總結
1. 大幅下殺為初步判定條件
2. 下殺當下並非進場時機
3. 需經過至少10-30根以上大週
   期Ｋ棒反彈
4. 反彈後若無Ｖ轉才能構成設計
   條件
5. 以不破底為猜想進場，風報比
   須合理適當
6. 屬於大週期策略

## 小師弟
小師弟型態特點
 屬性：中性
 週期：短週期
 時框：通常使用15分Ｋ
 勝率：中性
 報酬：中性
 頻率：高（幣圈）
小師弟型態判斷重點
1. 分Ｋ緩跌跌勢後急殺（通常
   為15分Ｋ）
2. 前方緩跌為價跌量平穩
3. 通常緩跌最後帶有急殺階段
   （並非每次都有）
4. 急殺Ｋ棒常伴隨大量或爆量
5. 急殺後預期彈升
6. 透過彈升幅度做策略設計
小師弟型態作法重點
1. 現象發生再設計單子，目前
   以ETH較有規律，其餘小幣
   SOP作法待開發
2. ETH明顯起跌分Ｋ至少超過
   100點
3. 最低點彈升至少為下跌段跌
   幅的40-50%以上
4. 根據上述條件滿足後設計適
   當風報比進場
總結
1. 中性策略
2. 牛熊市、盤整皆有出現機會
3. 嚴守策略篩網、不過度最佳化
4. 短週期（15分Ｋ）策略，可依
   照時框放大，唯放大至4H以
   上則類似『大師兄型態戰法』
5. 型態判定關鍵在於需具有一定
   的『彈升幅度』，才能夠顯現
   多頭力道足以支持進場理由

## 瘸師弟
瘸師弟型態特點
 屬性：逆勢
 週期：短週期
 時框：通常使用15分Ｋ
 勝率：中性稍高
 報酬：中性
 頻率：弱勢盤整期較多
瘸師弟型態判斷重點
1. 爆量＋長黑，缺一不可
2. 爆量判定為平均量Ｎ倍
3. 長 黑 為 瞬 間 單 根 較 大 跌 勢
   （大幣平均2%、小幣4-5%
   以上）
4. 策略預期數根Ｋ棒內會再度
   破底（搶後續市場流動性）
5. 勿過度追求參數最佳化
瘸師弟型態作法重點
1. 勿預期進場做空，等待現象
   發生再動作
2. 強勢標的較容易強彈高報酬
3. 平時需掌握強勢觀察標的
4. 現象發生後低掛％數進場
5. ％數因大幣小幣有所差異
6. 根據進場點做保本因應或目
   標停利
總結
1. 短期逆勢策略，停損紀律
2. 長黑＋爆量現象缺一不可
3. 低掛盲猜點位進場，可有可無
4. 根據進場點位以保本思維或目
   標停利（固定Ｒ出場）
5. 強勢標的較容易出現強彈
6. 平時掌握強勢標的族群
7. 『不追價、買下跌』
